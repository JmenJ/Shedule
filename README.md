# Shedule

Telegram-бот с расписанием в личном чате или учебной группе. Личное расписание можно позже подключить к одной или нескольким Telegram-группам без повторного заполнения.

## Что умеет

- владелец бота создаёт одноразовый код или персональную ссылку доступа;
- пользователь активирует расписание командой `/setup КОД` прямо в ЛС с ботом и становится его владельцем;
- личное расписание полностью работает без Telegram-группы: просмотр, редактирование и утренняя рассылка доступны в ЛС;
- владелец расписания создаёт командой `/copy` одноразовый код и подключает дополнительные чаты командой `/copy КОД`;
- у объединённых чатов общие расписание, настройки, подгруппы, владелец и модераторы;
- у каждой группы свои расписание, часовой пояс, чередование недель и тексты;
- расписание верхней и нижней недели редактируется кнопками прямо в Telegram;
- занятия можно переставлять кнопками «↑» и «↓»;
- время занятий бот рассчитывает по текущему порядку и обновляет после перестановки;
- время 1–8-й пары настраивается один раз для группы и автоматически подставляется во все дни, недели и рассылки;
- для каждой группы можно создать до восьми подгрупп с отдельными занятиями;
- участник выбирает свою подгруппу в меню расписания, а общие занятия показываются всем;
- утренняя рассылка автоматически отправляет расписание на текущий день по часовому поясу группы;
- владелец группы назначает собственных модераторов, не затрагивая другие группы;
- владелец может передать владение группой другому модератору или Telegram-администратору;
- текущая неделя вычисляется от выбранной опорной недели и меняется каждый понедельник;
- старое расписание из первой версии доступно как необязательный шаблон.

## Важно: смените токен

В старой версии токен находился прямо в `main.py` и попал в историю публичного репозитория. Считайте его скомпрометированным: отзовите старый токен в BotFather и создайте новый. Новый токен храните только в переменной окружения `BOT_TOKEN`.

## Переменные окружения

Скопируйте `.env.example` в настройки окружения хостинга:

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | новый токен BotFather |
| `BOT_OWNER_IDS` | Telegram ID владельцев через запятую; ID можно узнать через служебного Telegram-бота вроде `@userinfobot`, а после запуска проверить командой `/myid` |
| `DATABASE_URL` | PostgreSQL URL на Render; локально можно не задавать |
| `WEBHOOK_URL` | публичный HTTPS-адрес сервиса без завершающего `/` |
| `WEBHOOK_SECRET` | длинная случайная строка из букв, цифр, `_` и `-` |
| `DEFAULT_TIMEZONE` | часовой пояс новых групп, например `Europe/Moscow` |
| `SETUP_CODE_TTL_HOURS` | срок действия кода подключения, по умолчанию 24 часа |
| `PORT` | порт веб-сервера, обычно Render задаёт его сам |

Секрет для webhook можно создать локально командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## Развёртывание на Render

1. Создайте Render PostgreSQL и скопируйте Internal Database URL в `DATABASE_URL` веб-сервиса.
2. Добавьте остальные переменные окружения из таблицы выше.
3. Укажите Build Command: `pip install -r requirements.txt`.
4. Укажите Start Command: `python main.py`.
5. В `WEBHOOK_URL` укажите адрес сервиса, например `https://schedule.example.onrender.com`.

SQLite (`schedule.db`) включается автоматически только для локальной разработки. На обычном диске бесплатного веб-сервиса Render такая база может пропасть после перезапуска, поэтому в production нужен PostgreSQL либо подключённый persistent disk.

## Личный доступ и последующее подключение группы

1. В личном чате с ботом владелец выполняет `/admin`.
2. Нажимает «Создать код доступа» и выбирает пустое или старое расписание.
3. Передаёт человеку код либо сформированную ботом персональную ссылку.
4. Пользователь открывает ссылку или отправляет боту в ЛС `/setup КОД`.
5. После активации он пользуется `/start` и `/settings` прямо в личном чате.
6. Когда понадобится группа, владелец отправляет в ЛС `/copy` или нажимает `/settings` → «Подключить группу».
7. Бота добавляют в новую группу и отправляют там `/copy КОД`.

Код одноразовый и действует ограниченное время. Человек, первым активировавший `/setup КОД`, становится владельцем расписания. Личный чат и подключённая позже группа используют одни данные. Быть администратором Telegram-группы ему не требуется. Код также можно активировать сразу внутри группы, если личный режим не нужен.

## Объединение нескольких чатов

Если одни и те же студенты находятся в нескольких Telegram-чатах, дублировать расписание вручную не нужно:

1. В уже настроенной исходной группе владелец расписания отправляет `/copy`.
2. Бот выдаёт одноразовый код объединения.
3. Бота добавляют во второй, ещё не настроенный чат.
4. В новом чате любой участник, которому передали код, отправляет `/copy КОД`.
5. Для третьего чата владелец снова создаёт новый код командой `/copy` и повторяет подключение.

После объединения это одна логическая группа: изменения расписания, названия, часового пояса, подгрупп, рассылки, владельца и модераторов сразу видны во всех чатах. Код не выдаёт человеку новые права: владельцем и модераторами остаются пользователи исходной группы. Утренняя рассылка приходит отдельно в каждый подключённый чат.

Код действует столько же, сколько код `/setup`, и используется только один раз. Объединить можно только ещё не настроенный чат — это защищает существующие группы от случайной замены их данных.

## Помощь внутри Telegram

Команда `/help` сама учитывает место вызова и права пользователя. В личном чате владелец бота получает инструкцию по кодам подключения. В группе обычный участник видит просмотр расписания и личную настройку подгруппы, модератор — инструменты редактирования, а владелец группы — ещё управление ролями, передачу владения и `/copy`.

Если группа ещё не подключена, `/help` подскажет участнику с кодом порядок настройки и объяснит, что после подключения он станет владельцем.

## Модераторы группы

В `/settings` → «Модераторы» владелец может выбрать одного из Telegram-администраторов группы. Обычного участника можно назначить командой `/mod_add`, отправленной в ответ на его сообщение. Снять роль можно кнопкой в меню либо `/mod_remove` в ответ на сообщение.

Модератор может менять расписание и параметры своей группы, но не может выдавать роли. Глобальный владелец из `BOT_OWNER_IDS` имеет доступ ко всем группам.

В том же разделе владелец может нажать «Передать владение», выбрать нового владельца и подтвердить действие. Предыдущий владелец останется модератором, поэтому случайно потерять доступ к настройкам нельзя.

## Подгруппы и порядок занятий

В `/settings` → «Подгруппы» можно добавить, переименовать или удалить подгруппу. При удалении также удаляется её отдельное расписание; общие занятия не затрагиваются.

При редактировании расписания сначала выбирается область: «Общее расписание» или конкретная подгруппа. В дневном списке кнопки «↑» и «↓» меняют порядок занятий. При первом открытии дня бот просит участника выбрать подгруппу и запоминает её для всей логической группы, включая объединённые чаты. В следующих просмотрах выбор больше не показывается. Если участник ошибся, он меняет свою подгруппу через `/settings` → «Изменить подгруппу».

В обычном выводе расписания нет кнопки редактирования. Управление расписанием доступно владельцу и модераторам только через команду `/settings`.

В один день можно добавить до восьми занятий. Вводить время в названии предмета не нужно: оно берётся из общей настройки по порядковому номеру. После перестановки занятия кнопками «↑» и «↓» бот автоматически покажет время его новой позиции. В готовом расписании номера не выводятся: строка выглядит как `08:00–09:30: Математика`.

## Время занятий 1–8

Откройте `/settings` → «Время занятий 1–8». Интервалы можно менять по одному либо нажать «Задать несколько одним сообщением» и отправить список:

```text
1. 08:00-09:30
2. 09:40-11:10
3. 11:20-12:50
```

Можно перечислить любое количество номеров от 1 до 8 — остальные интервалы останутся без изменений. Чтобы удалить отдельный интервал, откройте его кнопку и отправьте `-`.

Настройка общая для верхней и нижней недели, всех подгрупп и всех объединённых чатов. Она применяется как к обычному просмотру, так и к утренней рассылке. При первом запуске обновлённой версии бот извлекает прежние интервалы из существующих текстов занятий и переносит их в общую настройку; повторяющееся время из названий удаляется автоматически.

## Утренняя рассылка

В `/settings` → «Утренняя рассылка» задаются состояние и местное время отправки. Бот использует часовой пояс группы и отправляет расписание один раз в день в каждый объединённый чат. Если подгруппы не созданы, приходит одно общее сообщение; если созданы — отдельное сообщение для каждой подгруппы с добавленными общими занятиями.

Проверка запускается каждые 30 секунд, а запись об отправке хранится в базе. Поэтому перезапуск сервиса не приводит к повторной рассылке за тот же день.

## Локальный запуск

Задайте `BOT_TOKEN` и `BOT_OWNER_IDS`, но не задавайте `WEBHOOK_URL`. Тогда бот автоматически запустится в режиме polling:

```bash
pip install -r requirements.txt
python main.py
```
